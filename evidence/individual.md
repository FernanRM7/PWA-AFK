Excluí métodos distintos de `GET`, otros orígenes, rutas sensibles y solicitudes con `Authorization`, `Cookie` o `Cache-Control: no-store` para evitar cachear datos sensibles o PII.
- **Comandos o pruebas ejecutadas:** `npm run test:vitest -- tests/service-worker.spec.ts`, `npm run test:vitest`, `npx tsc --noEmit`, `npm run verify`, `make verify` y `bash public-tests/check.sh`.

Las pruebas verifican instalación, activación, limpieza controlada, fetch, fallback de navegación offline, exclusión de solicitudes sensibles y conservación de la caché anterior cuando falla una actualización.
- **Regresión que detectan las pruebas:** fallan si no se crea el precache, si `activate` elimina una caché ajena o no elimina una versión antigua, si una navegación offline no devuelve la shell, si una solicitud sensible se guarda o si una actualización fallida elimina la caché previa.
