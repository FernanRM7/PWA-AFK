# Kit de instrucciones — Actividad 1

Lean `ASSIGNMENT.md`: contiene la ruta completa, rúbrica y entrega en equipo. `ACLARACION.md` explica cómo conservar el trabajo ya realizado.

Este kit no es el proyecto. El proyecto está en `PWA-starter.zip` y contiene una copia de las instrucciones como `ACTIVIDAD-01.md`. Descompriman ambos ZIP por separado. No mezclen carpetas, plantillas ni workflows. El starter ya incluye el workflow necesario.

Un repositorio privado por equipo y una entrega en Classroom por integrante, con los mismos enlaces y SHA y evidencia personal identificada. Los checks solo ofrecen feedback técnico; la calidad documental se revisa con la rúbrica.
